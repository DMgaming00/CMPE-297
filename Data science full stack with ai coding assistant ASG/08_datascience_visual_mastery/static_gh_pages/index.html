Vectorized Backpropagation in 4 Lines

The mathematical heart of modern deep learning executed in pure vectorized NumPy:

# Forward Pass cached: x (input), z = W @ x + b, a = phi(z) delta = grad_from_above * phi_prime(z) # elementwise: dL/dz for this layer grad_W = delta @ x.T # gradient for weight matrix grad_b = delta # gradient for bias vector grad_to_below = W.T @ delta # message routed to previous layer
