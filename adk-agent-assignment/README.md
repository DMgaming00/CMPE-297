# Google ADK Agent Assignment

> **Status: work in progress.** This folder is a placeholder. The full implementation will be added here when it is complete.

Five agents built with the Google Agent Development Kit (ADK):

| # | Agent | Architecture pattern | Key technology |
|---|---|---|---|
| A | Deep Research Lead Agent | Multi-agent research pipeline | ADK + Gemini + Google Search |
| B | Gemini CLI Engineering Agent | External tool orchestration | ADK + Gemini CLI |
| C | Software Bug Assistant | MCP tool orchestration | ADK + MCP |
| D | Code Review Assistant | Specialist review pipeline | ADK + static analysis |
| E | E-Commerce Agent | Transactional database agent | ADK + MCP Toolbox + PostgreSQL/AlloyDB |

## Configuration

Copy `.env.example` to `.env` and fill in your own values. Never commit `.env`.
